# 💎 Orixia | Luxury Accommodation Booking Platform

Orixia is a modern, high-end accommodation booking website built entirely with **Vanilla HTML, CSS, and JavaScript**. Designed with a sophisticated dark emerald and gold color palette, it delivers a premium, luxury hotel experience right in the browser. 

## 🚀 Live Demo
👉 **[Experience the Live Orixia Platform]([ https://kgosana950.github.io/Orixia/])**

## ✨ Features

*   **Luxury UI/UX:** A refined, expensive aesthetic using the `Cinzel` and `Montserrat` fonts, custom gold gradients, and a deep emerald theme.
*   **Interactive Booking Widget:** A fully functional hero section where users can select check-in/check-out dates and the number of guests.
*   **Room Showcase:** Displays room types (Executive, Deluxe, Standard) with dynamic images and dual-pricing (Nightly and Monthly rates).
*   **Simulated Database (LocalStorage):** Clicking "Book" opens a modal where users enter their details. The data is then saved to the browser's `localStorage`, mimicking a real backend database.
*   **Admin Dashboard:** A hidden link in the footer allows the admin (you) to view all booking requests saved in the simulated database.
*   **Fully Responsive:** Adapts seamlessly to mobile, tablet, and desktop views, complete with a hamburger menu for mobile users.

## 🛠️ Tech Stack

*   **HTML5:** Semantic structure.
*   **CSS3:** Custom variables, Flexbox, CSS Grid, glassmorphism (backdrop-filter), and smooth keyframe animations.
*   **Vanilla JavaScript (ES6+):** DOM manipulation, modal logic, date validation, and LocalStorage database integration.
*   **Google Fonts:** `Cinzel` (Headings) and `Montserrat` (Body).
*   **Font Awesome:** For premium iconography.
